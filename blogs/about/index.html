名称
#

我是汤伟杰，昵称是GaleInk，在英语课上起的英文名是Gale。当时老师让我们用一个形容词来描述名字，我选了Breezing，虽然不是很恰当，但当时想的是Breezing gale带来的画面：风从身边经过，轻快地向前，不会为某一个地方停留；就像是逝去的时光一样（其实，Gale这个名字是某款游戏中的一个角色的名字，当时很喜欢这个角色的性格和背景故事，就直接拿来用了）。此外，微风还会让我联想夏天的傍晚在河边散步时的场景（见下图），尽管身体感受到的是微风，但是在回忆里，当时的人和物却能激起如狂风般的情绪。

这里还想再多说一点，回忆往往由当时的人、物、事、情感组成，在未来的某个时候，一旦看到或者听到当时的某个物，就会回忆起当时的场景。除了上面的那张照片，还有音乐这个物，下面这首曲子就是当时散步时一直听的：

我的游戏昵称是炫酷七彩馒头，灵感来源于游戏《Undertale》中的角色Sans（下图左），以及其众多同人作中的角色Ink!Sans（下图右）。这个昵称听起来很中二，不过我要的就是这种中二的感觉。

如果叫我的话，叫我的名字或者“馒头”，都是可以的。

作息
#

每天早上可以睡到自然醒，闹钟都吵不醒。没有过一次真正意义上的“通宵”，因为我害怕猝死；即使真的需要一整个晚上去做某些事情，我也会在中间趴着睡一会。

爱好
#

小时候（小学和初中）练过书法，拿过几个没什么含金量的奖，字写的还算可以吧，至少够考试和平常用。

小时候（小学）没事的时候去广场打过篮球、羽毛球、乒乓球，都会一点，但不多，能当成娱乐项目去打。

游戏方面的话，喜欢玩各种音游，比如移动端的《Phigros》、《Dancerail3》、《Dynamix》，和街机音游《Chunithm》。对了，我采购了Chunithm（中二节奏）的手台，目前在我的宿舍，如果有同校的同学感兴趣欢迎找我，来我宿舍体验👍

关于这个博客

初衷
#

在这个博客诞生之前，我写的一些笔记都存放在github上，一些会整理一下发到知乎上。但是知乎的编辑器实在是太难用了，而且也文章也不方便进行个性化整理，所以我想搞一个博客网站来放所有的文章，这样还能自己分门别类，方便自己未来查找阅读，以及其他人的参考。

特别是笔记，有些文字可能非常简略，是课堂上记录的只有我自己能看懂的东西，后续有时间会补充；有些则是经过我编辑打磨过的，大家应该都能看懂。

风格
#

这个博客网站用的是Hugo的框架，和Blowfish的主题。我觉得这个组合对于编辑和组织文章来说非常方便，不需要考虑太多前端的东西（不过现在可以用AI来完成前端的一些DIY了）；而且外观看起来也还算清新，深蓝色的背景我很喜欢。不过目前（2026/10/08）Blowfish官网的主题已经升级了几次，我个人觉得有很浓的AI味道，所以不打算升级，就一直用当前的这个版本吧。
